PAREZ - Shop Accounting System
==============================

1. Install Node.js 22+ from https://nodejs.org
2. Extract this folder to C:\parez
3. Double-click Start_Parez.bat
4. Browser opens → Setup shop → Login → Work

Backup: Dashboard → Backup → "Back up now" → downloads .db file
Receipt printer: connects via USB, works automatically

Support: contact your developer
